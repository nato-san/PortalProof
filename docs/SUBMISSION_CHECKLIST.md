# PortalProof Submission Checklist

## Check-in Submission / 中間提出

- [ ] Public GitHub repository / 公開GitHubリポジトリ
- [ ] Complete README / README
- [ ] Continuously updated development records / 継続的な開発記録
- [ ] Product architecture diagram / プロダクト構成図
- [ ] Portaldot testnet deployment information / Portaldotテストネットデプロイ情報
- [ ] Contract address / コントラクトアドレス
- [ ] Transaction hash / TxHash
- [ ] Explorer link if available / 可能ならExplorerリンク
- [ ] Initial demo material / 初期デモ資料
- [ ] Live demo link or video under 3 minutes / Webリンクまたは3分以内の動画

## Final Submission / 最終提出

- [ ] Project name / プロジェクト名
- [ ] Team members / チームメンバー
- [ ] One-sentence project overview / 1文概要
- [ ] Public GitHub repository / 公開GitHub
- [ ] Complete README / README
- [ ] Deployment instructions / デプロイ手順
- [ ] Project documentation / プロジェクトドキュメント
- [ ] Reproducible or runnable final code / 再現・実行可能な最終コード

- [ ] Pitch deck / ピッチ資料
- [ ] Contract address and transaction hash if applicable / 該当する場合はコントラクトアドレスとTxHash

## Do Not Forget / 忘れないこと

- The repository must remain public during the event.
- 日本語訳: イベント期間中、リポジトリは公開状態にする必要があります。

- At least 3 valid commits are required during the Hacker House period.
- 日本語訳: Hacker House期間中に3つ以上の有効なコミットが必要です。

- Code should be primarily produced during Oct 14 - Nov 6.
- 日本語訳: コードは主に10月14日から11月6日の間に作る必要があります。

- Do not commit the core module all at once in the last 24 hours.
- 日本語訳: 締切前24時間にコア部分を一気にコミットしてはいけません。
